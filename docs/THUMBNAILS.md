# Cart Thumbnails retired

The thumbnail plugin is replaced by [Pico8Pocket Offline Collections](OFFLINE-COLLECTIONS.md).
Keep the same `https://github.com/zenibako/pico8pocket` plugin URL in Pocket Sync;
the next complete release updates its plugin assets and menu. Native Pocket
asset browsing does not display the generated per-cart artwork.

Thumbnail generation commands and native/WASI thumbnail downloads are retired.
Existing `System/Library/Images/pico8/` files remain untouched, as do carts and saves.
The original design and hardware-test notes remain in the historical design docs.
